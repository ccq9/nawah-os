# nawah-os — PROJECT

الاسم المؤقت: nawah-os (اسم عمل قابل للتغيير بقرار من المستخدم؛ لا علاقة له بأي علامة تجارية). البرومبت الحاكم: OS-EXEC-AR 3.2 (docs/prompt/OS-EXEC-AR-v3.2.md).

## الهدف الثابت (متطلب المستخدم)

1. نظام تشغيل مستقل بنواة أصلية يملكها المشروع (المسار K). ليس توزيعة ولا نقلًا لنواة قائمة ولا محاكاة ويب.
2. المنتج الأول: نظام فعلي للحواسيب الشخصية x86-64 بإقلاع UEFI.
3. التوسع لاحقًا إلى الأجهزة المحمولة (نوع الجهاز وISA يُحسمان في M12؛ ARM64 مرشح لا وعد).
4. تجربة المستخدم: مطابقة منظمة للإعدادات والتبويب والسلوك والمسؤوليات المعمارية الموثقة لمرجع Windows 10 Pro 22H2 x64 (عائلة البناء 19045)، مع هوية بصرية وأصول أصلية.
5. العربية والإنجليزية ضمن النطاق منذ طبقة النص والواجهة.
6. الأمن وحفظ البيانات والاختبار والصيانة منذ M0.

## النطاق الكامل مقابل إصدار الحاسوب الأول

- النطاق الكامل: البنود 1–6 أعلاه بكل مراحل M0–M15.
- R1 (أول إصدار حاسوب، معرَّف هنا كإصدار محدود معلن): إقلاع UEFI → نواة بذاكرة وعمليات معزولة ونداءات نظام → تخزين virtio-blk ونظام ملفات بسيط يحفظ البيانات بعد إعادة التشغيل → shell نصي → منصة رسوم وإدخال أساسية بقفل جلسة موثوق → واجهة سطح مكتب أساسية بثلاث صفحات إعدادات مطابقة للمرجع، بالعربية والإنجليزية. ما بعده (الجرد الكامل، التوافق، التثبيت والتحديث) إصدارات تالية داخل النطاق نفسه، لا خارجه.
- R1 لا يُعاد تعريف المطلب الكامل على مقاسه؛ وقبول الحاسوب لا يعلن اكتمال هدف المحمول.

## أبعاد المطابقة (تُحكم كل واحدة على حدة)

تشابه مرئي | سلوك | تقارب معماري | API | ABI | توافق تطبيقات. نجاح بُعد لا يثبت غيره. مصفوفات الحكم في docs/reference/windows10.json وdocs/settings.json وdocs/app-compatibility.json عند مراحلها.

## تعريفات الإصدارات

- MVP: R1 يقلع ويعمل على مختبر pc-qemu بكل بوابات M1–M7 الخاصة بنطاق R1 ناجحة.
- Alpha: MVP + مثبّت على قرص افتراضي فارغ وتحديث موقع (M9) على المحاكي.
- Beta: Alpha + تشغيل على جهاز حقيقي واحد مدرج في docs/hardware.json بأدلة، وجرد إعدادات R1 كامل.
- Release Candidate: Beta + مراجع مستقل أعاد حزمة القبول (البند 22.6) + لا عيوب حرجة/عالية مفتوحة + manifest وSBOM وتراخيص.

## حدود القبول لكل إصدار

كل إصدار يُقبل فقط بصيغة البند 22: «اجتاز الإصدار المحدد معايير القبول المحددة على البيئة المحددة، مع المخاطر والقيود الآتية». نطاق الدعم هو ما تثبته docs/hardware.json وdocs/settings.json بالأدلة.

## المستخدمون

مستخدم حاسوب شخصي يتوقع تنظيم Windows 10 وسلوكه بالعربية أو الإنجليزية؛ ومطوّر يستعمل SDK النظام لاحقًا (M8).
