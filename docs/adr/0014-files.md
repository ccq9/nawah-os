# ADR-0014 — الملفات عبر المقابض (WP-19)

الحالة: مقبول — منفَّذ ومُغلق 2026-10-18 بدليل CI run 39111422991 (TST-M3-FILE-ROUNDTRIP / PATH-INVALID / FD-LEAK PASS مع فحوص المضيف `fat32.py expect/check` و`fsck.fat -n`). درس التشغيل الأول (39110182649): الاختبارات الثلاثة أخفقت بـ #PF نواة في أول `open` لأن سجلات virtio كانت مرسومة في نصف المستخدم — أُصلح في vmm (ADR-0013 §8)، وهذه الاختبارات هي أول ما يمارس التخزين من مسار syscall.

المراجع: ADR-0011 (المقابض والحقوق)، ADR-0013 (FAT32 وأداة المضيف)، ADR-0012 (التطبيقات)؛ docs/contracts/files.md؛ Zircon «handles» كمرجع تصميمي (S39).

## القرارات

1. **لا جدول واصفات منفصل**: الملف المفتوح نوع كائن (`Object::File`) في جدول المقابض نفسه؛ حقوق READ/WRITE تتبع أعلام الفتح، و`handle_close`/`handle_duplicate`/التمرير عبر القنوات تعمل عليه بلا شيفرة خاصة. خروج العملية يُسقط الجدول فتُغلق الملفات (REQ-M3-008: لا تسريب واصفات) — يقيسه `fd_leak` بعدّادات حية (`files`، `handles`) لا بالادعاء.
2. **طبقة `fs::vfs` رقيقة**: فحص المسار (مطلق، ASCII، ≤ 256) ثم تفويض إلى FAT32؛ كائن الملف = نسخة من إدخال المجلد + موضع مشترك خلف `IrqSpinLock` (ترتيب الأقفال: ملف → fs → blk). لا ذاكرة مخبّأة للإدخالات: كائنان لملف واحد لا يتزامن حجمهما (قيد مسجَّل في العقد؛ يُعالج مع نظام ملفات داخلي أو vnode cache في M4).
3. **نداءات 13–19 إضافية** (v1.3) بالترتيب نفسه: المقبض ثم النوع ثم الحق ثم المؤشرات ثم القرص؛ النقل ≤ 64 KiB لكل نداء عبر مخزن نواة على الكومة؛ `stat` يكتب 16 بايت ثابتة.
4. **اختبارات كتطبيقات Rust** (file_roundtrip، path_invalid، fd_leak) مبنية بـ libnawah، رمز الخروج = رقم الخطوة الفاشلة؛ النواة تتحقق من الكائنات والإطارات والعناقيد حول التشغيل، والمضيف (`tools/fat32.py expect/check`، `fsck.fat -n`) يقرأ الصورة بعده — ثلاثة منفّذين على البيانات نفسها.
5. لا تغيير في خط أساس unsafe (160): كل الشيفرة الجديدة آمنة.

## الاختبارات

- TST-M3-FILE-ROUNDTRIP: التطبيق يخرج 0x60 (16 خطوة)؛ `/APP.TXT` = `written by BYle_roundtrip: second part\n` كما تقرأه الأداة المضيفة؛ لا كائن أو مقبض أو إطار بعده.
- TST-M3-PATH-INVALID: 20 رفضًا برموزها (غير موجود، نسبي، اسم غير 8.3، مجلد، مرور عبر ملف، أعلام فارغة/غير معرَّفة، مجلد أب مفقود، stat/unlink، مسار فارغ/NUL/طويل، مؤشر نواة، مقبض سيئ، مقبض قناة لنداء ملف) ثم قراءة صحيحة؛ خروج 0x61.
- TST-M3-FD-LEAK: خروج 0x62 بـ 44 مقبضًا مفتوحًا؛ بعده files=0، handles=0، الأحجام 1500×4، العناقيد الحرة ناقصة 12 بالضبط، الإطارات متساوية؛ المضيف: `fsck.fat -n` و`fat32.py check`.
