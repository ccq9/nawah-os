# عقد الإدخال — الإصدار 1 (WP-27، ADR-0017)

مجمَّد (أُغلق WP-27 بدليل CI run 39134727743): أي تغيير في الكائن أو النداء = إصدار جديد مع سجل قرار. الكود: `kernel/src/arch/x86_64/i8042.rs` (المتحكم)، `kernel/src/object/bytes.rs` (الكائن؛ كان `kbd.rs` قبل WP-30 الذي عمّمه لقناة التشخيص بلا تغيير في السلوك)، `kernel/src/net.rs` (`tick_poll`)، `user/apps/kbdprobe` (الاختبار من حلقة 3).

- **المصدر**: لوحة مفاتيح PS/2 عبر متحكم i8042 (منافذ 60h/64h؛ S52) كما تركه البرنامج الثابت: الواجهة المساعدة (الفأرة) تُعطَّل عند الإقلاع بالأمر A7h، ولا تُغيَّر مجموعة الرموز (الترجمة إلى **المجموعة 1** على QEMU: `a` = 1E/9E، `b` = 30/B0، Enter = 1C/9C).
- **الاستطلاع**: لا IRQ 1 بعد (ADR-0005): نبضة المؤقت على المعالج 0 تقرأ حتى 8 بايتات لكل نبضة من المخزن الخارج عندما يشير بت 0 في الحالة إلى وجود بايت؛ بايتات الفأرة (بت 5) تُسقط. حد المعدل بهذا ≈ 8000 بايت/ثانية.
- **الكائن** `Object::Keyboard` (رمز النوع 8): حلقة 64 بايتًا؛ الفيض يُسقط الأحدث ويزيد `overflow`. الحقوق `READ|WAIT|DUPLICATE|TRANSFER`. إشارة `READABLE` ما دامت بايتات في الحلقة. تنشئه النواة وتسلّمه لمدير الخدمات، وهو يسلّمه للخدمة المسماة `input` (services.md §4).

| الرقم | الاسم | الوسائط | النتيجة |
|---|---|---|---|
| 31 | `kbd_read` | h, ptr, cap (1..=64) | عدد البايتات المنسوخة (≥ 1)، أو `ERR_SHOULD_WAIT`؛ `ERR_INVALID` لسعة 0؛ `ERR_ACCESS` بلا READ |

- **الاختبار الحاكم** TST-M4-KBD-SCANCODES: الاختبار يعلن الجاهزية، المختبر يحقن `a`، `b`، Enter عبر مراقب QEMU (`sendkey`؛ S54)، وعملية `kbdprobe` تستلم البايتات الستة بالترتيب وتخرج بها مرصوفة.
- **خارج الإصدار**: فك الرموز إلى محارف وتخطيط لوحة المفاتيح (M5 مع وحدة التحكم)؛ الفأرة؛ USB HID.
