# عقد الـ shell التشخيصي — الإصدار 0 (مسودة M4، ADR-0016)

مسودة تخطيط: تُجمَّد كإصدار 1 عند إغلاق حزمتها بدليل CI؛ ما لم يُنفَّذ منها لا يُعدّ مدعومًا.

- **القناة**: 16550 ثانٍ (COM2، 0x2F8) يربطه المختبر بمقبس TCP؛ أسطر ASCII تنتهي بـ`\n`، الموجه `nawah> ` أو `user@nawah> `.
- **الأوامر**: `svc` (يسأل svcmgr)، `cpu` (المعالجات والنبضات من النواة)، `mem` (الإطارات الحرة من النواة)، `net` (يسأل netd)، `ls path`، `cat path` (ملفات الحجم)، `login name password`، `logout`، `help`.
- **الحقيقة من مالكها**: كل أمر يستعلم الخدمة أو النواة وقت التنفيذ؛ لا حالة مخبأة في الـ shell.
- **السلطة**: الأوامر المحمية (`svc stop`, `cfg set`) تمر بالرمز الحالي؛ بلا رمز → `ERR_ACCESS`.
