# عقد عناصر الواجهة والوصول — الإصدار 1 (WP-36، ADR-0019 §7)

**مجمَّد** (أُغلق WP-36 بدليل CI run 39163664738): أي تغيير في العناصر أو المفاتيح أو الأوصاف أو المسار = إصدار جديد مع سجل قرار. الكود: `user/libui` (المكتبة: `no_std`، بلا تخصيص، بلا `unsafe`، فوق `nawah-text`)، `user/apps/narrator` (قارئ الشاشة النصي)، `user/apps/dialog` (حوار العيّنة)، `user/apps/displayd` (التمرير، display.md v1.1)، `tools/transcript.py` (فحص المختبر).

## 1. العناصر

- `Dialog::add(role, label)` و`add_list(label, items)`: الأدوار `label` (غير قابل للتركيز)، `button`، `textfield`، `list` (حتى 6 عناصر)، `checkbox`؛ حتى 12 عنصرًا. **تسمية فارغة أو مسافات فقط تُرفض** (`UiError::NoLabel`، وكذلك عنصر قائمة فارغ؛ القائمة بلا عناصر `NoItems`): لا يُبنى عنصر بلا تسمية. التسميات والقيم UTF-8.
- **التخطيط**: عمود بعرض 260 وحدة وحشوة 6؛ الارتفاعات: تسمية 20، زر وحقل 26، مربع اختيار 22، قائمة 20 × (1 + العناصر)؛ الوحدة × المقياس. الاتجاه RTL/LTR للحوار كله (محاذاة النص ومكان المربع)؛ النص نفسه يمر بـ UAX #9 (text.md) فلا عكس آلي لكلمة أو رقم أو مسار.
- **المقياس والتباين** من `config` (المخزن `device`): `ui.scale` = `1` | `1.5` | `2` (غير ذلك 1×)، `ui.contrast` = `high` (غير ذلك عادي)؛ يُقرآن عند البدء ويُتابَعان بـ `SUBSCRIBE device`: كل مفتاح يتغيّر يُقرأ وحده فيُطبَّق بترتيب التغييرات. الخط 14 بكسل × المقياس. لوحتان: عادية (خلفية F0F0F0، نص 101010، حلقة تركيز 1E64C8) وتباين عالٍ (خلفية 000000، نص FFFFFF، حلقة FFFF00، التحديد أصفر بنص أسود). أكبر حوار (2×) يسع سطح VMO واحدًا.

## 2. التركيز والمفاتيح (ضغطات فقط؛ رموز input.md)

ترتيب التركيز = ترتيب الإعلان دون التسميات، ثابت. `Tab` التالي و`Shift+Tab` السابق (دوريًا)؛ `Esc` إلغاء (الحوار ينتهي). في الحقل: المحارف (والعربية) تُدرج عند المؤشر، `Backspace` يحذف قبله، `←`/`→` المؤشر، `Enter` تفعيل. في القائمة: `↑`/`↓` التحديد ضمن الحدود، `Enter` تفعيل. المربع: `Space`/`Enter` تبديل. الزر: `Space`/`Enter` تفعيل.

## 3. الأوصاف ومسار القارئ

- الوصف: `role=<role> label="<label>" state=<حالات>` ثم ` value="<نص>"` للحقل أو ` item="<عنصر>" index=<k>/<n>` للقائمة؛ الحالات بفواصل: `focused` للمركَّز، `static` للتسمية، `checked`/`unchecked` للمربع، `enabled` لغير المركَّز من الباقي.
- التطبيق يرسل إلى الـ compositor `A11Y <wid> <نص>`؛ الحوار يعلن عند البدء `tree k/n <وصف>` لكل عنصر بالترتيب المعلن ثم `focus <وصف>`، وبعد كل مفتاح `focus …` / `change …` / `activate …` / `cancel`، وعند تغيّر المظهر `theme scale=<ربع> contrast=<normal|high>`.
- الـ compositor يمرّر إعلان **النافذة المركَّزة وحدها** إلى القارئ المسجَّل (`SAY <نص>`؛ display.md v1.1) ويعلن هو `window "<العنوان>" focused` عند انتقال التركيز بين النوافذ؛ إعلان نافذة غير مركَّزة يُرفض (`ERR NOT_FOCUSED`) فلا يتكلم تطبيق فوق آخر.
- `narrator` يكتب كل `SAY` على قناة التشخيص `narrator|<نص>`، والمحارف غير ASCII بصيغة `\u{XXXX}`؛ الصوت لاحق.

## 4. الاختبارات الحاكمة

- TST-M5-UI-UNIT (مضيف): الرفض عند البناء، ترتيب التركيز، المفاتيح، الأوصاف بالحرف، المظهر من التكوين، تضاعف المستطيلات، ألوان الرسم.
- TST-M5-KEYBOARD-NAV (ضيف، تشغيلان): نص القارئ = `platform/pc-qemu/expect/keyboard-nav.txt` حرفيًا في كلا التشغيلين.
- TST-M5-A11Y-TREE (ضيف): نص القارئ = `expect/a11y-tree.txt`؛ `ui.scale=2` يضاعف الحوار بالأصل نفسه، `ui.contrast=high` يغيّر اللوحة (لقطة الشاشة: الخلفية والحلقة).
- TST-M5-UI-TOOL (مضيف): فحص النص والأبعاد.
