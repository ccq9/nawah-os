# عقد عناصر الواجهة والوصول — الإصدار 0 (مسودة M5، ADR-0019 §7)

مسودة تخطيط: تُجمَّد كإصدار 1 عند إغلاق WP-36 بدليل CI؛ ما لم يُنفَّذ منها لا يُعدّ مدعومًا.

- **المكتبة** `libui` (no_std، فوق libnawah-display وlibnawah-text): عناصر `Window`، `Button`، `Label`، `TextField` (bidi، مؤشر، تحديد)، `List`، `Checkbox`، `ScrollView`؛ تخطيط أعمدة/صفوف بسيط مع RTL/LTR حسب لغة الواجهة (لا عكس آلي للأيقونات أو المسارات: §17).
- **التركيز**: شجرة تركيز بترتيب معلن ثابت؛ `Tab`/`Shift+Tab` بين العناصر، الأسهم داخل القوائم، `Enter` تفعيل، `Esc` إلغاء/إغلاق؛ كل تغيير تركيز يُعلَن.
- **الوصول**: لكل عنصر تسمية ودور وحالة (`role=button label="…" state=focused,checked…`)؛ الـ compositor يحمل إعلانات التركيز والتغييرات على قناة `a11y` إلى خدمة `narrator` التي تكتبها نصًا على قناة التشخيص (M5؛ الصوت لاحق). عنصر بلا تسمية خطأ بناء (يُرفض في `libui`).
- **المقاييس**: تكبير النص 1×/1.5×/2× وتباين عالٍ وتقليل الحركة من `config` (`policy`/`user` مفتاح `ui.scale`, `ui.contrast`, `ui.motion`) تُقرأ عند البدء وتُتابَع بـ `SUBSCRIBE`.
- **الاختبارات الحاكمة**: TST-M5-KEYBOARD-NAV، TST-M5-A11Y-TREE (حوار عينة: زر، حقل نص، قائمة، مربع اختيار).
