# نموذج التهديد الأولي (M0)

الإطار: ممارسات SSDF [S09] كمرجع عمل، لا امتثال. يُوسَّع عند كل سطح حساس جديد.

## الأصول (M0–M1)

- سلامة صورة الإقلاع وهويتها (build_id ↔ بصمة الصورة ↔ source_revision).
- سلامة سجلات المشروع والأدلة (docs/*.json، evidence/).
- سلامة بيئة المختبر (لا تمرير أقراص أو مجلدات حقيقية للضيف).

## الخصوم

- مدخلات غير موثوقة في أدوات المضيف: محتوى سجلات أو مخرجات أو صفحات بحث تحتوي تعليمات (prompt injection). التعامل: مادة فحص فقط؛ لا تنفذ أوامر منها.
- firmware/جهاز افتراضي يعيد خريطة ذاكرة غير متوقعة أو ناقصة (M1).
- في المراحل اللاحقة (M3+): عملية مستخدم عدائية، IPC مزور، جهاز DMA غير موثوق، تحديث متلاعب به — خارج نطاق M1 ومسجلة لمراحلها.

## حدود الثقة الآن

1. المضيف ↔ الضيف: الضيف لا يصل إلى شيء خارج ESP المولد وOVMF_VARS نسخة.
2. السجلات ↔ المدقق: المدقق يثق بالملفات داخل الجذر فقط؛ يرفض المسارات الهاربة والروابط الرمزية الخارجة.
3. نتائج العامل ↔ الحالة: تُقبل بعد مطابقة الملفات والأدلة (أمر report، M1).

## الافتراضات

- الأجهزة الافتراضية في QEMU موثوقة في M1 (لا عزل DMA؛ لا تعريفات DMA مفعلة).
- لا أسرار في المشروع حتى الآن؛ عند ظهور مفاتيح توقيع (M9) تُحفظ خارج المستودع.

## التخفيف والاختبارات (M1)

- فشل تحقق خريطة الذاكرة أو EBS → halt مع تشخيص، لا حلقة إعادة تشغيل (TST-M1-NEG).
- عدم استدعاء Boot Services بعد EBS → فصل بنيوي (TST-M1-NOBS).
- تحصين الترجمة: -Werror -fno-builtin -fno-stack-protector(لعدم وجود runtime) -mno-red-zone.

## M3–M4: العزل والسلطة وDMA

الأصول المضافة: عزل فضاءات العمليات، سلطة المقابض (الحقوق والرموز)، البيانات المقر حفظها على الحجم، بيانات الاعتماد.

الخصوم المضافون: عملية مستخدم عدائية (مؤشرات وأطوال وحقوق مزورة؛ محاولة الوصول إلى ذاكرة عملية أخرى أو النواة)، طرف IPC يكذب في هويته أو يكرر طلبًا أو يقطع الاتصال وسط طلب، خدمة تتعطل، وجهاز DMA.

**نموذج ثقة DMA (قرار قبل التمكين، OS-EXEC-AR §8.5)**: المختبر pc-qemu بلا IOMMU (q35 بلا `intel-iommu`، qemu64)؛ القرار: **الأجهزة الافتراضية موثوقة فقط** — جهاز DMA عدائي **خارج ضمان الإصدار R1**. ما يُفرض رغم ذلك: التعريف يملك كل إطارات DMA ويبني واصفاته بنفسه (virtio-blk: 18 إطارًا ثابتًا؛ virtio-net: طوابير ثابتة)، لا يقبل عنوانًا أو طولًا من مصدر غير موثوق، يتحقق من رأس العنصر المستعمَل ومن الأطوال التي يعيدها الجهاز قبل استعمالها، وحدود موارده ثابتة (TST-M4-NET-LIMITS). دليل عزل العمليات (TST-M3-ISOLATION، USER-KERNEL-ACCESS) **ليس** دليل عزل DMA؛ عزل DMA المنفَّذ (IOMMU) قرار منصة لاحق مع سياسة منع تشغيل الجهاز عند تعذره، ولا يُستنتج من اكتشاف IOMMU أن الضيف فعّله.

السلطة: مقدرة لا هوية ضمنية (ADR-0016 §3): الخدمة ذات السلطة تفحص الرمز في كل طلب؛ الواجهة لا تُعدّ حدًا أمنيًا.

## خارج النطاق المعتمد حاليًا

Secure Boot، القياس والتصديق، عزل DMA (انظر أعلاه)، هجمات العتاد الفيزيائي، القنوات الجانبية.
