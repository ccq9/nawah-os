# TST-M5-LOCK-HANG (WP-40, services.md v1.7): the session stack of TST-M5-LOCK-SURVIVES, but the
# compositor and the input service are watchdog-monitored and restart on failure. While the
# session is locked the test wedges the live compositor, then the live input service
# (sched::freeze_named); for each the manager's watchdog must miss the PONG, force-kill it and
# restart it — without the lock dropping or a key reaching the spy.
auth /SYSTEM/AUTHD.ELF - 60000 never 0 0
input /SYSTEM/INPUTD.ELF - 5000 on-failure 3 10 watchdog=200
display /SYSTEM/DISPLAYD.ELF input 5000 on-failure 3 10 watchdog=200
session /SYSTEM/SESSIOND.ELF auth,input,display 5000 never 0 0
spy /SYSTEM/SPY.ELF display 5000 never 0 0
